Customizable 3D model of the time machine from "The Visitor from the Future". Made using OpenSCAD.
Original design by Olivier Marten. Keys were made using KeyV2 https://github.com/rsheldiii/Keyv2
I also copied code from https://openhome.cc/eGossip/OpenSCAD/SectorArc.html (for the arcs) and https://www.thingiverse.com/thing:8443 (for the bezier curves).
I included free use images I printed to decorate my print. https://www.needpix.com/photo/96122/mp3-player-ipod-mp3-music-songs-device-portable-music-player-multimedia https://www.filterforge.com/filters/2056.html

The repo also contains links to my references (Olivier Marten's work).
